# Changelog

## 1.0.0 — 2026-10-08

First companion source release for the book's first edition, researched through 2026-10-04.

- Preserve the book's ten Python source listings without modification.
- Package twelve deterministic scenarios, six field-exercise fixtures, the optional local-model proposal adapter, and the paired-statistics utility.
- Add platform-specific quick starts, learner and advanced reading paths, scenario runbooks, PASTA measurement guidance, and troubleshooting.
- Add campaign/finding templates, observed synthetic example evidence, and clearly labeled illustrative paired outcomes.
- Add extra field/statistics tests, a single validation command, an integrity manifest, and a GitHub Actions matrix.

The release does not introduce a new protocol implementation or claim live-model efficacy. See [verification](docs/verification.md) for executed checks and untested platforms.
